# 上相机条码回检与下相机对齐设计

## 目标

使上相机条码二次回检的处理规则与现有下相机回检保持一致，同时保留已实现的“同批模组全部完成回检后再返回错误”行为。

## 适用范围

- 仅处理开启上相机扫码模式及条码回检开关时的工站上相机回检。
- 覆盖普通飞拍回检和最后位置回检两条路径。
- 不修改下相机现有行为，也不改变放偏、面积、连接器的报警逻辑。

## 行为

1. 上相机首次回检读到的条码为空或与工站记录不一致时，定位到该模组位置并执行一次单点重拍。
2. 单点重拍读到非空条码但仍与记录不一致时，将该工站模组结果写为 `111`，记录错误日志，并继续同批其他模组的回检。
3. 单点重拍仍读不到条码时，复用下相机的弹窗语义：
   - `bBackerrcontinue` 开启：显示继续运行、重新拍照、停止运行；继续运行和重新拍照都回到当前点重拍。
   - `bBackerrcontinue` 关闭：显示重新拍照、停止运行；重新拍照回到当前点重拍。
   - 停止运行：立即结束当前流程，并保留尚未完成的回检模组供恢复运行后继续回检。
4. 同批条码不一致只在所有可处理模组完成后返回 `RETRY`；不再由第一颗不一致直接跳过其他模组。
5. 标记为 `111` 的模组由既有下料规则送往 NG 料盘；本次不修改料盘下料调度。

## 实现位置

- `UI/Class/UpDownLoad.cs`
  - `FlyCamToTray` 的上相机普通回检循环。
  - `FlyCamToLastPos` 的上相机最后位置回检循环。
  - 提取共享的上相机条码单点重拍与弹窗处理，避免两条路径产生不一致实现。

## 验证

1. 上相机首次条码不一致、重拍仍不一致：结果为 `111`，同批另一颗仍完成回检。
2. 上相机读空：弹窗后选择重拍或继续运行，均持续对当前点重拍；选择停止运行则立即结束。
3. 上相机条码正确：不增加额外单点移动或重拍。
4. `111` 模组恢复运行后按既有流程下入 NG 料盘。
