# pre-mini 手动传感器读取设计

## 目标

在“系统设置 / 参数1 / pre-mini自动点检串口”中，让右、左工站均能分别手动读取距离，以及照度/色温；每一次手动操作都能在运行日志中留下完整、可定位的串口追踪信息。

## 界面

现有每个工站已配置一个“综合COM”，并已有一个“综合读取”按钮和隐藏的光学读取按钮。本次不增加新的布局行：

- 将“综合读取”改为“测量距离”。
- 将紧邻的隐藏“读光1”改为可见的“测量照度/色温”。
- 两个按钮均使用本工站的“综合COM”。

这样右、左工站各有一对独立按钮，复用已验证的控件坐标，不会与既有控件重叠。

## 读取与日志

- `ManualReadDistance` 只开启激光、读取距离一次，结束时关闭激光；不移动任何机械轴。
- `ManualReadLuxCct` 只发送 Lux/CCT 读取命令一次；不移动 Z 轴、不改变光源状态。
- 手动读取会记录开始、COM、发送命令、收到的原始串口数据、帧头/长度/JSON 解析异常，以及成功值或超时前的发送与回包统计。
- 自动点检维持既有测量与判定流程；本次不改变阈值、三点 Z 移动或 NG 判定。

## 验证

1. 静态回归检查先确认独立公开读取 API 和四个 UI 事件绑定尚不存在，因此应失败。
2. 完成代码后该检查必须通过。
3. 编译 `UI.sln`，确认 WinForms Designer 与事件处理均可编译。
