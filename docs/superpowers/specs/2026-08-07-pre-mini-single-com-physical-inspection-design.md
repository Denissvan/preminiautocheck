# Pre-Mini 单 COM 物理点检设计

**状态：** 已确认

## 目标

将 Pre-Mini 的物理点检从“每工站一个距离 COM 加三个 Lux/CCT COM”收敛为“每工站一个综合点检 COM”。该 COM 对同一工站同时提供距离、照度和色温数据。

每个启用点检的测试位必须完成：

1. 一次距离测量。
2. 在 Z1、Z2、Z3 三个位置分别进行一次照度与色温测量。
3. 对每次读取的值分别按该测试位的标准值和阈值判定。

## 不在范围内

- 九点照度或色温均匀度判定。
- 标板信息读取。
- 普通 MINI 的测试电脑工厂模式点检、PUCF DLL 调用或测试电脑模式切换。
- 定时时间触发策略；该设计只覆盖单次物理点检的配置、执行和失败处理。

## 配置与界面

产品配置文件 `UI\\bin\\product\\<产品名>\\ptcfg.ini` 的 `[AutoCheckParam]` 节只保留：

```ini
PreMiniWs1AutoCheckCom=COMx
PreMiniWs2AutoCheckCom=COMy
```

仍保留现有的工位启用开关、点检时间、点检起始测试位和各工站的 Z1/Z2/Z3 位置配置。

停止读取和写入下列旧字段：

- `PreMiniWs1DistanceCom`
- `PreMiniWs2DistanceCom`
- `PreMiniWs1LuxCctCom1` 至 `PreMiniWs1LuxCctCom3`
- `PreMiniWs2LuxCctCom1` 至 `PreMiniWs2LuxCctCom3`

设置页每个工站只显示一个“综合点检 COM”下拉框和一个“综合读取”按钮。保存时执行以下校验：

- 已启用点检的工站必须配置 COM。
- 两个工站同时启用时，两个 COM 不能相同。
- 旧 COM 字段不迁移；新版配置为空时要求人工选择综合 COM，避免根据旧配置推断硬件连线。

## 单次点检流程

对一个已启用点检的测试位：

1. 打开该工站的唯一综合 COM，并在本测试位完成前保持打开。
2. 打开激光，执行距离读取；单次尝试读取两次，以第二次数据参加判定；随后关闭激光。
3. 距离超限时最多自动尝试三轮。三轮都失败时，弹窗提供“重新测量”和“停止”。重新测量只重做距离阶段。
4. 距离通过后，依次移动到 Z1、Z2、Z3。每个位置从同一 COM 读取一次 Lux/CCT，并分别以 `ActualLuxParam`、`LuxThreshold`、`ActualCctParam`、`CctThreshold` 判定。
5. 任一光学位置发生超限、串口读取失败或运动失败时，先尝试回到该测试位 Z1，再弹出“重新测量”和“停止”。重新测量从 Z1 开始重做整轮光学扫描。
6. 距离和三处光学点检均通过后，记录本测试位点检成功并关闭 COM。

点检启用后，COM 为空、无法打开、协议响应缺少所需字段或读取超时，均为失败；不允许跳过该点继续测试。

## 代码边界

- `MotionCtrl/Class/MyType.cs`：定义、加载和保存两个综合 COM 配置字段。
- `UI/FormView/FrSys.Designer.cs`：将页面控件收敛为每工站一个 COM 和一个手动读取按钮。
- `UI/FormView/FrSys.cs`：加载、保存、校验和手动综合读取。
- `UI/Class/PreMiniAutoChecker.cs`：复用一个 `SensorReader` 完成距离和三个 Z 位置的 Lux/CCT 读取；实现普通 MINI 风格的重测/停止处理。
- `UI/Class/WSFEED.cs`：保留调度职责，移除现有“重测 / 跳过 / 停止”中的跳过分支，只接收成功或停止结果。

## 验收标准

1. 工位 1 和工位 2 可以独立保存综合 COM；程序重启后设置保持不变。
2. 两个已启用工位不能保存相同 COM；未配置 COM 的启用工位不能启动点检。
3. 每个启用点检的测试位产生一条距离记录和三条 Lux/CCT 记录，记录包含工位、测试位、Z 序号、COM 与测量值。
4. 距离超限时最多执行三轮自动尝试；三轮失败后仅允许重测距离或停止。
5. Z1、Z2、Z3 任一处的照度、色温、串口或运动错误均只允许重测整轮光学扫描或停止。
6. 光学扫描成功或失败后，设备回到该测试位 Z1。
7. 不执行均匀度、标板读取、PUCF 工厂模式控制，且不存在跳过后标记为点检成功的路径。
